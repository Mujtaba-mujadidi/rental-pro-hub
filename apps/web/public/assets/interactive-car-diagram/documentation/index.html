Including Files

These are required files you need to import in your page so the Car Diagram can work.

 <link href="assets/css/cardiagram.css" rel="stylesheet">

 <script src="assets/js/cardiagram.js"></script>

It's not required, but I recommend placing the CSS files in <head> and the JavaScript files and initialization code in the footer of your site (before the closing </body> tag). Also if you already have jquery.js on your site, don’t include it a second time.

HTML

You need to add HTML codes between <body> </body>.

<div class="digram-box">.....................</div>
